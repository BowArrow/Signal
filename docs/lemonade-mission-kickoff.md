# Lemonade: first sales test

Mission: $100,000 USD in new collected payments from October 13 through December 31, 2026, Pacific time. Refunds reduce the score; disputed payments remain excluded. No additional advertising budget is authorized.

First checkpoint: five paying customers who can explain the task Lemonade helped them complete. This is an experiment, not a sales forecast. At the current $49 personal price, the full target would require 2,041 full-price licences before refunds and discounts. The current 10% team discount changes that arithmetic.

## Audience and offer

Start with solo consultants and small-business owners who compare client reports or supplier documents. This is a buyer hypothesis supported by the product's current file comparison and editable-document workflows; it is not validated demand. Use the existing 14-day free trial and $49 perpetual licence. Keep pricing unchanged.

The first channel test uses the existing professional audience on the connected LinkedIn account, with one shorter version for the connected Bluesky account. We do not know either account's effective buyer reach. No post is public until its exact copy and destination are approved.

## How this test becomes useful

After an approved publication, record the actual post URL. Check relevant replies within one working day and prepare an individual response to the person's stated task. Ask for human help with commitments, support questions or unclear product fit. No unsolicited direct messages are part of this test.

After 72 hours, compare publication receipts, available site sessions, relevant conversations and any captured payments. A view, like, download or reply is not a sale. If the posts receive no relevant response, investigate audience and placement before producing more versions of the same post. If people try the product, use their actual questions and voluntary feedback to identify the next obstacle. Do not add behavioral telemetry to the desktop app.
